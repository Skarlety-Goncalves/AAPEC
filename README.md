# AAPEC — Site acadêmico

Projeto de redesign institucional da AAPEC para trabalho acadêmico.

## Tecnologias
- HTML5
- CSS3
- JavaScript

## Rodar no VS Code
1. Abra esta pasta no VS Code.
2. Abra `index.html`.
3. Use o Live Server.

## Alterações desta versão
- Campanhas agora exibem somente as quatro artes fornecidas, com os meses correspondentes:
  - Setembro Verde
  - Outubro Rosa
  - Novembro Azul
  - Dezembro Laranja
- O botão `Busco acolhimento` abre o WhatsApp da AAPEC.
- Mantidos o layout, navegação, rodapé, contatos, Brechó e demais páginas da versão anterior.

# AAPEC — Site acadêmico de redesign

Versão corrigida e simplificada para uso no VS Code com Live Server.

## Estrutura
- `index.html` — página inicial
- `paginas/sobre.html` — Sobre nós
- `paginas/servicos.html` — Serviços
- `paginas/campanhas.html` — Campanhas
- `paginas/ajudar.html` — Como ajudar
- `paginas/contato.html` — Contato
- `css/style.css` — estilos
- `js/script.js` — menu mobile e ano do rodapé
- `img/` — logo e fotos fornecidas

## Alterações desta versão
- Retorno ao layout anterior, sem a seção "Conheça nossas ações" e sem cards de projetos.
- Projeto 1 e Projeto 2 são usados somente como imagens de apoio nos espaços visuais.
- Comunidade removida de menus e páginas.
- Todos os cards clicáveis.
- Botão "Busco acolhimento" leva para Contato.
- Brechó abre o Instagram informado.
- Endereço do Brechó incluído na página de Campanhas.
- Contatos oficiais aplicados em todo o site.
- Caminhos relativos corrigidos para funcionar com Live Server.
